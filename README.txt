Студия‑Н — сайт для загрузки на хостинг
=========================================

Структура
  index.html      — страница
  support.js      — скрипт отрисовки (обязателен)
  media/          — картинки (WebP в нескольких размерах + JPG‑запасные) и видео hero

Как выложить по FTP
1. Загрузите ВСЁ содержимое архива в корень сайта (public_html / www / htdocs), сохраняя структуру папок.
2. Откройте https://studia-n.com/ — сайт должен открыться сразу.

Что сделано для скорости на мобильных
- Браузер сам выбирает размер картинки под экран (srcset), формат WebP — страница на телефоне весит ~0,3 МБ вместо 3+ МБ.
- Картинки ниже первого экрана подгружаются лениво, по мере прокрутки.
- Фоновое видео hero на телефонах (до 860px), при включённом «уменьшении движения» и Data Saver не загружается — показывается постер.
- Шрифты подключены только в используемых начертаниях.

Примечания
- Шрифты (Google Fonts) и библиотека интерфейса (unpkg.com) подгружаются из интернета.
- privacy.html возьмите со старого сайта и положите рядом с index.html — на него ведёт ссылка в футере.
